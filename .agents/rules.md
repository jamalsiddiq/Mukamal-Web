# Mukamal Project Rules

## 01 — The "Top 1%" Mandate
Every output — every audit, every report, every line of code — must be best-in-class. If it isn't Top 1%, the execution is a failure. No exceptions.

## 02 — Minimalist Tone
All system responses, documentation, and deliverables must be clinical, declarative, and data-backed. Zero AI fluff. Zero filler. Every word earns its seat.

## 03 — Logic Dictates Layout
UX interactions are mapped psychologically before they are visualized. Structure precedes style. Math precedes taste.

## 04 — Zero-Bloat Process
Assets and procedures are stripped of cognitive friction. Cookie modals are removed before visual audits. Redundant steps are eliminated. Clean workspace, always.

## 05 — Two-Layer Skill Delegation
- **Domain tasks** (auditing, designing, publishing, distributing) → route through the Mukamal pipeline skills in `skills/`.
- **Meta tasks** (creating, updating, testing, versioning, archiving skills) → route through Global Skills at `~/Documents/Global Skills/`.
- Never duplicate functionality across layers.

## 06 — Pipeline Integrity
All 7 phases of the pipeline execute in strict sequence. Each phase's output is the next phase's input. Any failure halts the chain — no skip-ahead, no partial runs.

## 07 — Pristine Workspace
All assets are stored in their logic-appropriate pillar directory:
- Audit media → `01_Audit_Engine/[brand]/media/`
- Audit reports → `01_Audit_Engine/[brand]/reports/`
- Design tokens → `03_System_Designer/`
- Published assets → `04_Mukamal_Web/`
- Distribution logs → `05_Content_Forge/`

## 08 — Human-in-the-Loop (HITL) Gates
AI handles data acquisition, heuristic scoring, layout scaffolding, and outreach orchestration. Humans own brand taste, narrative validation, heuristic database curation (via Notebook LM), and high-ticket sales closes.

## 09 — Evidence-Based Authenticity
Every statement, score, and assumption made in an audit must be backed by undeniable, cited evidence. No single assumption is permitted. Every heuristic validation must include a reference to a specific element within the capture or DOM. Prove it, or remove it.
