# Harvesting Brand Tokens Workflow

Scrape, audit, and enforce AAA-grade design tokens from live DOM.

## Steps

1. Read the skill definition at `skills/harvesting-brand-tokens/SKILL.md`.
2. Identify the target URL and scope (full-page or component-level).
3. Scrape the live DOM for color, typography, spacing, and elevation tokens.
4. Audit each token against Top 1% standards (AAA contrast, grid alignment, font scale consistency).
5. Output a clean, deduplicated token inventory with pass/fail annotations.
6. Route clean tokens to `skills/designing-systems` for synthesis.
