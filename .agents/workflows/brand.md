# Brand Architect Workflow

Activate the Brand Architect to manage all brand-related tasks.

## Steps

1. Read the skill definition at `skills/brand-architect/SKILL.md`.
2. Determine the request type:
   - **Audit:** Check a target (website section, case study, content) against brand guidelines
   - **Generate:** Create brand assets (OG images, social headers, favicons, presentations)
   - **Tokens:** Query or update the canonical design token set
   - **Evolve:** Propose and implement brand positioning changes
3. Execute per the skill's `<instructions>`.
4. Store generated assets at `04_Mukamal_Web/assets/brand/`.
5. If brand tokens were changed, propagate updates to `ux-ui-designer`, `web-master`, and `content-writer` skills.

## Usage Examples
- *"Audit the hero section for brand compliance"*
- *"Generate an OG image for the web3 case study"*
- *"Show me the current brand tokens"*
- *"Update the primary accent color to a warmer green"*
