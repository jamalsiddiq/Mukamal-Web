# Designing Systems Workflow

Transform broken UX metrics into Figma-ready tokens, structural layouts, and perfected flows.

## Steps

1. Read the skill definition at `skills/designing-systems/SKILL.md`.
2. Load the audit failure report from `01_Audit_Engine/[brand]/reports/`.
3. Load harvested brand tokens (if available) from `skills/harvesting-brand-tokens`.
4. Diagnose root structural causes for each critical failure.
5. Compute corrected layouts using mathematical grid parameters.
6. Output Figma-ready specifications and design tokens as structured JSON.
7. Assemble the complete "Perfected Flow" specification.
